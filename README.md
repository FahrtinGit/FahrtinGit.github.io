# Bilder til "Om oss"

Legg bildene av gruppemedlemmene i denne mappen. Filnavnet må matche navnet
som brukes i `index.html` nøyaktig (inkludert stor forbokstav og filtype):

- `Fahrtin.jpg`
- `Dawit.jpg`
- `Elias.jpg`

Så snart et bilde ligger her med riktig navn, dukker det automatisk opp på
"Om oss"-siden i stedet for de gule bokstav-initialene.
